# Sales, Profit & Discount Analysis Dashboard

## Project Overview
This project analyzes Superstore sales data using Microsoft Excel. It focuses on understanding sales performance, profit, discounts, product categories, and yearly sales trends.

## Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Excel Dashboard

## Dataset
- 8,399 records
- 21 columns
- Order, customer, product, sales, discount, and profit details

## Key Analysis
- Province-wise Sales Analysis
- Product Category-wise Sales
- Product Category-wise Profit
- Average Discount by Category
- Sales by Order Priority
- Year-wise Sales Analysis

## Key Insights
- Total Sales: 14,915,600.82
- Total Profit: 1,521,767.98
- Technology generated the highest sales and profit among the three product categories.
- Office Supplies had the highest average discount.
- 2009 recorded the highest sales among the years analyzed.

## Project Objective
To practice data cleaning, data analysis, Pivot Tables, and dashboard creation using Excel, while developing business insights from sales data.
